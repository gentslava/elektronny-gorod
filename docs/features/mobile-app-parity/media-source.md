# Архив камер через Media Source

Интеграция публикует нативный Home Assistant Media Source: журнал событий
движения камер («Электронный город» в Media Browser) с воспроизведением
mp4-клипов.

## Структура

Аккаунт → Адрес → Камера → День → События. Событие отображается строкой
«ЧЧ:ММ:СС · длительность записи» — единицы локализуются по языку инстанса HA (ru: «X мин Y сек», en: «X min Y sec»); серые строки — записи, недоступные для скачивания
(не сохранилась или истёк retention). Retention: 14 дней для домофонов,
7 дней для остальных камер.

## Воспроизведение

По клику интеграция запрашивает у оператора подписанную ссылку
`forpost/events/{id}/downloads` и стримит клип через Home Assistant:
браузер получает только same-origin ссылку (`/api/...`) с короткоживущим
подписанным токеном. Это обходит блокировку браузеров (ORB) — оператор
отдаёт файл как octet-stream+attachment. Оператор готовит mp4 по
требованию: первый клик может занять до ~30 секунд (сервер рендерит
клип, интеграция опрашивает статус). Перемотка работает: клип
скачивается целиком и держится в памяти на время жизни ссылки, а
диапазоны Home Assistant отдаёт сам. Подписанная ссылка оператора не
покидает сервер HA и нигде не логируется.

Отказы оператора приходят уже после открытия плеера, поэтому выглядят
как обычная ошибка воспроизведения: отсутствие записи и выход за окно
хранения дают 404, «клип ещё готовится» — 503, недоступность оператора —
502. Причина пишется в журнал Home Assistant; в большинстве случаев
достаточно повторить клик через несколько секунд.

## Доступ

Источник виден всем авторизованным пользователям Home Assistant (так же,
как встроенные media sources). Камеры, скрытые в реестре сущностей HA
(«Показывать на панели» выключен), исключаются из списка и из
воспроизведения. Камеры с отключённой (disabled), но не скрытой сущностью
по-прежнему видны в архиве — скрытие выполняется только через
«Показывать на панели». Личные камеры не входят в этот slice.

## Ограничения

- Перемотка/стриминг архива по таймлайну (как в мобильном приложении) не
  реализованы — только клипы по событиям.
- Эскизы событий не передаются; подписанные ссылки работают ограниченное
  время.
