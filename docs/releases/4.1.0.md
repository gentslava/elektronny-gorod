# v4.1.0 — Архив камер в медиабраузере

Записи с камер теперь можно смотреть прямо в Home Assistant. В разделе «Мультимедиа» появился источник «Электронный город»: аккаунт → адрес → камера → день → события движения. Клип открывается по клику, перемотка работает, а подписанная ссылка оператора не покидает сервер.

Обновление не содержит breaking changes и не требует переавторизации.

## 🎬 Что нового

- **Архив камер как нативный Media Source.** Дерево повторяет логику мобильного приложения. Событие подписано временем и длительностью записи; переводы есть для русского и английского интерфейса.
- **Воспроизведение с перемоткой.** Home Assistant забирает файл у оператора целиком, держит его на время жизни ссылки и сам отдаёт браузеру нужные фрагменты. Без этого перемотка не работала бы вовсе: видеохранилище оператора не поддерживает запросы по диапазонам байт.
- **Глубина по сроку хранения.** 14 дней для домофонов, 7 дней для остальных камер. Запрос за пределами окна даёт понятное сообщение, а не общую ошибку камеры.
- **Скрытые камеры остаются скрытыми.** Камеры, выключенные переключателем «Показывать на панели», не попадают в архив ни в списке, ни при воспроизведении. Видимость проверяется и по флагу оператора, и по реестру сущностей, поэтому камера остаётся скрытой даже до того, как для неё создана сущность.
- **Ожидание вместо ошибки.** Оператор готовит mp4 по требованию. Первый клик по свежему событию занимает несколько секунд — интеграция дожидается готовности сама, опрашивая сервер с тем же интервалом, что и мобильное приложение.

## 🔐 Доступ к записям

Ссылка, которую получает браузер, ведёт на сам Home Assistant, действует ограниченное время и **открывается без повторного входа**. Это тот же приём, что у штатных прокси камер и TTS в Home Assistant: тег `<video>` не умеет прикладывать сессию, поэтому доступ подтверждается подписью в самой ссылке. Практический вывод один: не пересылайте такую ссылку посторонним.

Подписанная ссылка оператора при этом никуда не уходит — она используется только на сервере и не попадает ни в браузер, ни в журнал, ни в диагностическую выгрузку.

Кеш записей ограничен и по размеру одного ролика, и суммарно, а при удалении аккаунта из Home Assistant освобождается сразу.

## ✅ Breaking changes

Нет. Версия config entry не менялась, миграция не требуется, новых обязательных настроек не появилось.

## ⚠️ Ограничения среза

- Только клипы по событиям движения — перемотки по непрерывному таймлайну нет.
- Эскизы событий не передаются.
- Личные камеры не поддерживаются.

## ⬆️ Как обновиться

1. Обновите интеграцию до 4.1.0 через HACS.
2. Перезапустите Home Assistant.
3. Откройте «Мультимедиа» и разверните источник «Электронный город».

Удалять интеграцию и проходить авторизацию заново не нужно.
